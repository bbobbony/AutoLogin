# Global 영웅문 자동 로그인 프로그램

> 글로벌 영웅문 실행부터 로그인까지의 반복 과정을  
> OS 자동 실행 흐름에 포함시켜 사용자 개입 없이 처리하는 자동 로그인 프로그램

---

## 📌 프로젝트 소개
글로벌 영웅문(Global Hero) 프로그램 실행 시  
아이디 및 비밀번호 입력 과정을 자동화하여  
사용자 개입 없이 로그인까지 완료되도록 구현한 Python 기반 자동화 프로그램입니다.

---

## 🎯 개발 배경
주식 거래를 위해 글로벌 영웅문 프로그램을 사용할 때마다  
프로그램 실행 → 로그인 정보 입력 → 로그인 버튼 클릭 과정을 반복해야 했습니다.

특히 장 시작 전 아침 시간대에는  
로그인 과정 자체가 번거롭고 불필요한 작업으로 느껴졌고 
이를 자동화하여 로그인 과정을 최소화하고자 본 프로젝트를 개발했습니다.

---

## ⚙️ 자동화 시나리오
본 프로젝트는 단순한 로그인 자동화를 넘어 
운영체제(OS) 수준의 자동 실행 흐름을 고려하여 설계되었습니다.

1. 정해진 시간에 컴퓨터 전원 ON (OS 예약 기능 활용)
2. OS 시작 시 자동 로그인 프로그램 자동 실행
3. 글로벌 영웅문 프로그램 실행
4. 로그인 창 활성화 감지
5. 아이디 / 비밀번호 자동 입력
6. 로그인 버튼 클릭
7. 사용자 개입 없이 로그인 완료

---

## 🛠 기술 스택
- Language: Python (32bit && 64bit)
- Automation: pyautogui, pywin32
- UI: PySide6
- OS: Windows

> ※ 글로벌 영웅문 프로그램과의 호환성을 위해 Python 32bit 환경을 사용합니다.
